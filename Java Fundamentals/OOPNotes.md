
# Object-Oriented Programming in Java

Object-Oriented Programming (OOP) is a programming approach based on classes and objects.

## Core Concepts

### 1. Class
A class is a blueprint for creating objects.

### 2. Object
An object is an instance of a class.

### 3. Encapsulation
Encapsulation combines data and methods within a class and controls access to that data.

### 4. Inheritance
Inheritance allows one class to acquire properties and methods from another class.

### 5. Polymorphism
Polymorphism allows the same method or interface to behave differently in different situations.

### 6. Abstraction
Abstraction hides implementation details and exposes essential functionality.

## Language
Java
